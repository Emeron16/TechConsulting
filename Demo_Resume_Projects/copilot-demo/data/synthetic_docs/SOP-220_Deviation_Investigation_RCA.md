# SOP-220: Deviation Investigation and Root Cause Analysis

## 1. Purpose

Defines the required steps for investigating a manufacturing deviation once
it has been classified per SOP-114, including root cause analysis (RCA)
methodology and documentation standards.

## 2. Investigation Levels

- **Level 1 (Critical deviations):** Full RCA using the 5-Whys and
  Fishbone/Ishikawa method, cross-functional investigation team, QP sign-off
  required on the closure report.
- **Level 2 (Major deviations):** RCA using 5-Whys minimum, Quality Reviewer
  sign-off required on closure.
- **Level 3 (Minor deviations):** Abbreviated investigation, single
  investigator, logged in the deviation tracking system.

## 3. Root Cause Categories

Investigators must assign a root cause category from the standard taxonomy:

- Human error (procedure not followed)
- Equipment failure or malfunction
- Material/component nonconformance
- Procedure/SOP inadequacy (the SOP itself was unclear or incorrect)
- Environmental/utility failure
- Unknown/indeterminate (requires Quality Head approval to close as such)

## 4. Timeliness Requirements

- Critical deviations: investigation must be substantively complete within
  30 calendar days of identification; extensions require Site Quality Head
  approval and documented justification.
- Major deviations: 45 calendar days.
- Minor deviations: 90 calendar days.

## 5. Linkage to CAPA

If the root cause analysis concludes that a systemic or recurring issue
exists, a CAPA must be initiated per SOP-301 before the deviation
investigation can be closed. A deviation cannot be closed with an open
"CAPA required" determination and no linked CAPA record.
