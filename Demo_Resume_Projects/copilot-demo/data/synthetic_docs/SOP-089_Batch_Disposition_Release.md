# SOP-089: Batch Disposition and Release

## 1. Purpose

Defines the requirements for dispositioning a manufactured batch (release,
reject, or rework) and the role of open deviations in that decision.

## 2. Disposition and Open Deviations

A batch **cannot** be released while it has an open Critical or Major
deviation associated with it, per SOP-114 classification. Minor deviations
do not block release but must be documented in the batch disposition record.

## 3. Disposition Roles

- **Quality Reviewer:** compiles the batch record review packet, confirms
  all deviations are closed or appropriately dispositioned, prepares the
  release recommendation.
- **Qualified Person (QP):** reviews the complete batch record, deviation
  history, and CAPA status, and issues the final release decision. This is
  a legally designated role and cannot be delegated to an automated system.

## 4. Rework and Reject Criteria

A batch is rejected (not reworked) if the deviation involves a confirmed
patient-safety impact per SOP-114 Section 3.1. Rework is only permitted for
deviations where the root cause (per SOP-220) is process- or
equipment-related and a validated rework procedure exists for the specific
product.
